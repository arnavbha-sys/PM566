Problem 1: Vectorization

The following functions can be written more efficiently without using parallelization. For each function, I created a faster version, verified its output, and compared its speed with the original version.

1. Generating a matrix of Poisson random variables

The original function repeatedly uses rbind() inside a loop. This is inefficient because R must repeatedly allocate and copy the growing matrix. The alternative generates all values at once and places them into a matrix.

fun1 <- function(n = 100, k = 4, lambda = 4) {
  x <- NULL
  
  for (i in seq_len(n)) {
    x <- rbind(x, rpois(k, lambda))
  }
  
  return(x)
}

fun1alt <- function(n = 100, k = 4, lambda = 4) {
  matrix(
    rpois(n * k, lambda),
    nrow = n,
    ncol = k,
    byrow = TRUE
  )
}

Both functions should produce matrices with the same dimensions.

2. Finding the maximum value of each column

# Data-generating process: 10 x 1,000 matrix
set.seed(1234)
x <- matrix(rnorm(1e4), nrow = 10)

fun2 <- function(x) {
  apply(x, 2, max)
}

fun2alt <- function(x) {
  do.call(
    pmax,
    lapply(seq_len(nrow(x)), function(i) x[i, ])
  )
}

The alternative function passes the rows of the matrix to pmax(). This calculates the maximum across rows for every column.

The outputs of the two functions are identical.

Problem 3: Parallelization

Bootstrapping involves repeating the same calculation on many independently resampled datasets. Therefore, the bootstrap replications can be distributed across multiple processor cores.

1. Parallel bootstrap function

The function below uses parallel::mclapply() on macOS and Linux. On Windows, where forked processing is unavailable, it creates a PSOCK cluster and uses parallel::parLapply() instead.

When ncpus = 1L, the function uses the original serial lapply() method.

my_boot <- function(dat, stat, R, ncpus = 1L) {
  
  # Check the arguments
  stopifnot(
    is.data.frame(dat) || is.matrix(dat),
    is.function(stat),
    length(R) == 1L,
    R >= 1,
    length(ncpus) == 1L,
    ncpus >= 1
  )
  
  R <- as.integer(R)
  ncpus <- as.integer(ncpus)
  
  # Generate the bootstrap row indices
  n <- nrow(dat)
  idx <- matrix(
    sample.int(n, n * R, replace = TRUE),
    nrow = n,
    ncol = R
  )
  
  bootstrap_once <- function(i) {
    stat(dat[idx[, i], , drop = FALSE])
  }
  
  if (ncpus == 1L) {
    
    # Serial calculation
    ans <- lapply(seq_len(R), bootstrap_once)
    
  } else if (.Platform$OS.type != "windows") {
    
    # Parallel calculation for macOS and Linux
    ans <- parallel::mclapply(
      seq_len(R),
      bootstrap_once,
      mc.cores = ncpus
    )
    
  } else {
    
    # Parallel calculation for Windows
    cl <- parallel::makeCluster(ncpus)
    on.exit(parallel::stopCluster(cl), add = TRUE)
    
    parallel::clusterExport(
      cl,
      varlist = c("dat", "stat", "idx"),
      envir = environment()
    )
    
    ans <- parallel::parLapply(
      cl,
      seq_len(R),
      function(i) {
        stat(dat[idx[, i], , drop = FALSE])
      }
    )
  }
  
  # Convert the list of estimates into a matrix
  ans <- do.call(rbind, ans)
  
  return(ans)
}

2. Checking the bootstrap confidence intervals

The statistic used for this example contains the estimated intercept and slope from an ordinary least-squares regression.

# Bootstrap statistic for an OLS regression
my_stat <- function(d) {
  coef(lm(y ~ x, data = d))
}

# Simulate the data
set.seed(1)

n <- 500
R <- 1e4

x <- rnorm(n)
y <- 5 * x + rnorm(n)

simulation_data <- data.frame(x = x, y = y)

# Parametric confidence intervals
ans0 <- confint(lm(y ~ x, data = simulation_data))

# Bootstrap estimates
set.seed(1)

ans1 <- my_boot(
  dat = simulation_data,
  stat = my_stat,
  R = R,
  ncpus = 2L
)

# Bootstrap percentile confidence intervals
ans1_ci <- t(
  apply(
    ans1,
    2,
    quantile,
    probs = c(0.025, 0.975)
  )
)

ans1_ci
                  2.5%      97.5%
(Intercept) -0.1383681 0.04900409
x            4.8698329 5.04347278
ans0
                 2.5 %     97.5 %
(Intercept) -0.1379033 0.04797344
x            4.8650100 5.04883353

The bootstrap confidence intervals should be similar to the parametric confidence intervals returned by confint(). They will not be exactly identical because the bootstrap procedure is based on random resampling.
